## 🚀 Tech Stack
* **Framework**: [Next.js](https://nextjs.org) (App Router, Turbopack, TypeScript)
* **Styling**: Tailwind CSS v4 with custom architectural tokens (Warm Alabaster `#FAF8F5`, Champagne Bronze `#B4833E`, Emerald `#15803D`, Obsidian `#18181B`)
* **Animations**: [Lenis](https://lenis.darkroom.engineering) smooth inertia scrolling, [Framer Motion](https://motion.dev) scroll reveals, and [Swiper](https://swiperjs.com) Ken-Burns carousel
* **Icons**: [Lucide React](https://lucide.dev)
* **QA & Testing**: [Playwright](https://playwright.dev) headless audit for mobile and desktop

## 💻 Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build
```bash
npm run build
npm run start
```
